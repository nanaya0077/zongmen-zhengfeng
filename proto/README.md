# AI 原型 · v0.1

> 无界面模拟内核。目的是验证「AI 会不会招募、会不会派人出去占地」，不是游戏本体。
> 最后更新：2026-11-20

---

## 运行

```bash
cd slg/proto
node run.js [种子] [年数]
node run.js 20261120 60
```

输出：每 5 年一行势力概况，最后给统计表、地形图、势力图。

---

## 文件

| 文件 | 作用 |
|---|---|
| `world.js` | 地图生成（与《地图生成》同算法）、宗门、修士、修士属性 |
| `ai.js` | **招募**、**派遣**、寻路、移动与占格、势力范围并入 |
| `run.js` | 主循环：产出、建房、升级、一年腐烂、调用 AI、输出 |

## 观察到的四个问题

### 1. 修士上限会把地图占满

住房上限 160 床 × 10 家 = **1600 名修士**，而地图只有 **600 格**。
每人驻守一格 → 约 60 年全图占满（实测 99.2%）。

**要么**砍住房上限，**要么**承认「后期挤满、靠战争重分」是设计意图。

### 2. 灵石没有出口

60 年后各宗堆积 **15000 – 25000 灵石**。
因为「修炼加速 / 功法秘籍 / 法宝」都还没实现，灵石只进不出。

### 3. 没有矿山的宗门会卡死

天机阁、星河宗 60 年灵石恒为 **200**（初始值），等级卡在 Lv1。
因为灵石只产自山地，而它们的领地里没有山。

**这是设计特性还是缺陷？** 如果是特性，需要一个「没有灵石也能活」的保底。

### 4. 没有战斗 → 扩张到顶就静止

第 20 年后「本年占格」长期为 0：边界被邻居卡死，谁也吃不掉谁。
AI 的派遣逻辑此时只剩「原地站着」。
